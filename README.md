# TriSwitch 0.2.1

Переносимый переключатель раскладки для **русского, украинского и английского** в Windows 10/11 x64. Программа работает локально, без учётной записи и сетевых запросов.

Поддерживаются временные идентификаторы языковых профилей Windows, в том числе в новом Блокноте. Для них язык определяется по фактической раскладке клавиш; переключение направляется в активное поле ввода.

В стандартных полях Edit/RichEdit, включая новый Блокнот, текст заменяется одной операцией редактора с поддержкой отмены, без буфера обмена и эмуляции отдельных Unicode-клавиш. Режим `--notepad-test` проверяет этот путь в отдельном тестовом документе нового Блокнота (40 замен, переключение языков и отмена); результат записывается в `notepad-test-results.txt`.

## Запуск

Если вы скачали **исходники с GitHub**, сначала выполните `powershell -ExecutionPolicy Bypass -File .\build.ps1` в папке проекта. После сборки дважды щёлкните **Запустить.cmd**. В готовом комплекте запускайте **TriSwitch.exe**. Переносите всю папку `dist/TriSwitch`, включая `dictionaries`; одного EXE недостаточно. Установка и права администратора не нужны. Программа использует .NET Framework 4.8, входящий в современные Windows 10/11.

В Windows должны быть добавлены английская (США), русская и украинская раскладки. Их наличие видно в верхней части окна; после добавления раскладки нажмите «Обновить список раскладок» на вкладке «Настройки». На компьютере, где выполнена сборка, обнаружены все три.

По умолчанию программа запускается **сразу в трее, без появления главного окна**. Двойной щелчок по значку **3** или пункт «Открыть TriSwitch» открывает настройки. Закрытие окна возвращает программу в трей, пункт **Выход** в меню значка полностью завершает её. Аргумент `--show` открывает окно сразу; `--tray` также поддерживается.

На вкладке **«Настройки»** есть галочка **«Запускать при входе в Windows · сразу в трей»**. Она применяется сразу: включает или отключает автозапуск для текущего пользователя без прав администратора. По умолчанию автозапуск выключен. Используется только запись `TriSwitch` в `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`; настройки других программ не изменяются. После переноса папки программы включите галочку заново, чтобы обновить путь.

Если работает другой автоматический переключатель раскладок, приостановите его на время использования TriSwitch, чтобы две программы не исправляли одно слово одновременно.

## Использование

Автозамены включены по умолчанию и срабатывают **после пробела**. Сначала проверяются ваши правила, затем словари: словарная замена выполняется, если слово не найдено в текущем виде и есть ровно один вариант в другой раскладке. Примеры при вводе в EN:

| Набрано | Результат |
|---|---|
| `ghbdtn` + пробел | `привет ` и раскладка RU |
| `ghbdsn` + пробел | `привіт ` и раскладка UK |
| `руддщ` в RU + пробел | `hello ` и раскладка EN |
| `vfvf` + пробел | Остаётся как есть: «мама» допустима в RU и UK |

Словари распознают слова от четырёх символов. Слова с цифрами, адреса с `@`, URL с `://`, идентификаторы с `_` не исправляются по словарям; для них можно явно создать своё правило. Enter не вызывает автоисправление, чтобы не менять текст при отправке сообщения.

| Сочетание | Действие |
|---|---|
| **Ctrl + Alt + 1** | Последнее набранное слово → EN |
| **Ctrl + Alt + 2** | Последнее набранное слово → RU |
| **Ctrl + Alt + 3** | Последнее набранное слово → UK |
| **Ctrl + Alt + F6** | Перебрать EN → RU → UK → EN |
| **Ctrl + Alt + Backspace** | Отменить последнюю замену и вернуть исходную раскладку |
| **Ctrl + Alt + Space** | Пауза / продолжение |

В таблице указаны сочетания по умолчанию. На вкладке **«Горячие клавиши»** щёлкните нужное поле, нажмите новое сочетание и выберите **«Сохранить клавиши»**. Поддерживаются Ctrl/Alt с другими клавишами, дополнительно Shift; без Ctrl/Alt — F1–F11, F13–F24, Pause и Scroll Lock. F12 и сочетания с Win не назначаются. Delete или Backspace без модификаторов в поле назначения отключает действие; Tab переводит фокус в следующее поле.

Повторяющиеся и занятые сочетания не сохраняются. Новые назначения начинают работать сразу, прежние освобождаются. При конфликте или ошибке записи настроек остаются прежние назначения. «По умолчанию» заполняет поля стандартными значениями; для применения также нажмите «Сохранить клавиши». Подсказки на главной вкладке обновляются после сохранения.

Исправляется слово, набранное **после запуска программы**, до пробела или сразу после одного пробела. После начала следующего слова, движения курсора, щелчка мышью, вставки, Tab или Enter запомненное слово сбрасывается. Отмена доступна до такого сброса. Слово, исправление которого отменено, исключается из автоисправления до перезапуска.

Для произвольного текста есть вкладка **«Конвертер текста»**: вставьте текст, выберите исходную раскладку и целевой язык. Можно преобразовать выделенную часть. Кнопка «Копировать» явно записывает результат в буфер обмена; глобальное исправление слова буфер обмена не использует. Глобального преобразования произвольного выделения в чужом приложении нет.

## Свои замены

На вкладке **«Свои замены»** нажмите **«Добавить»**, заполните строку и нажмите **«Сохранить замены»**:

| Вкл. | Что заменить | На что заменить | Раскладка |
|---|---|---|---|
| Да | `brb` | `Скоро вернусь` | Не менять |
| Да | `адр` | `улица Мира, 10` | RU |
| Да | `ukr` | `Україна` | UK |

Это примеры; в новой установке список пуст. Правило заменяет **целое последнее слово**, без учёта регистра. По умолчанию результат вставляется буквально. Галочка **«Сохранять регистр»** переносит строчный, заглавный или полностью прописной регистр исходного слова на замену: `добрій → добрый`, `Добрій → Добрый`, `ДОБРІЙ → ДОБРЫЙ`. При смешанном регистре результат остаётся как записан. После изменения галочки нажмите **«Сохранить замены»**. Исходное слово — от 1 до 64 символов без пробелов; результат — от 1 до 512 символов, одна строка, может содержать пробелы. Эмодзи, комбинируемые символы и переносы строк в этой версии не поддерживаются. Ввод фразы из нескольких слов как исходного шаблона не поддерживается.

«Не менять» сохраняет раскладку; EN/RU/UK переключает её после замены. Пробел и завершающая пунктуация сохраняются. Точное правило с пунктуацией имеет приоритет: отдельное правило `brb!` сработает раньше `brb`. Для одинакового исходного слова можно включить только одно правило.

Свои правила имеют приоритет над словарями, поэтому могут заменять короткие, правильно написанные или неоднозначные слова. Исключения для слов и программ, пауза и общий флажок автозамен действуют и для них. Клавиша отмены возвращает исходное слово целиком; отменённое правило для этого слова не срабатывает до перезапуска. Автозамены не выполняются при редактировании настроек самой программы.

Снимите флажок «Вкл.», чтобы временно отключить правило, или выделите строки и нажмите «Удалить выбранные». После изменения нажмите «Сохранить замены». Сочетания клавиш и правила сохраняются в `settings.json` рядом с EXE. Настройки версии 0.1 загружаются с сохранением прежних исключений и режима работы.

## Исключения и защита текста

- На вкладке «Настройки» задаются исключения — имена процессов и слова, по одному на строку. Например, `Code`, `notepad` или `chrome`. Расширение `.exe` необязательно.
- Терминалы, несколько редакторов кода, клиент удалённого рабочего стола и распространённые менеджеры паролей исключены по умолчанию. Список можно изменить.
- Обработка отключается в полях, которые Windows помечает как пароль, в недоступных для редактирования полях и когда нельзя достоверно проверить свойства поля.
- Перед заменой сверяется текст непосредственно перед курсором. При выделении текста, изменении поля, потере фокуса или новом вводе отложенная замена отменяется.
- Программа не пишет журнал вводимого текста. Текущее слово, данные для одной отмены и ограниченный кэш словарных проверок находятся только в памяти. Настройки и явно добавленные исключения сохраняются в `settings.json` рядом с EXE.

Совместимость зависит от того, какие сведения приложение предоставляет через Windows UI Automation. Если приложение не даёт проверить положение курсора и текст, TriSwitch пропускает замену. Приложения с повышенными правами и нестандартные редакторы могут не поддерживаться. Проверки проведены на обычном текстовом поле Windows; совместимость со всеми браузерами, Word и мессенджерами не заявляется.

## Распознавание

В комплекте **527 588 словарных записей** из словарей LibreOffice/Hunspell. Читатель поддерживает исходные записи, одиночные префиксы/суффиксы и разрешённое сочетание префикса с суффиксом. Это ограниченная проверка словоформ, а не полная реализация Hunspell: сложные составные формы и цепочки дополнительных аффиксов могут быть пропущены.

Русско-украинская неоднозначность разрешается вручную; анализа контекста фразы в этой версии нет. Словари подтверждают существование слова, но не намерение автора: при ложном срабатывании используйте отмену или добавьте слово в исключения.

Преобразование при наличии установленных раскладок использует таблицы Windows, включая регистр. Для ручного конвертера при отсутствии раскладки есть резервная таблица US / стандартная ЙЦУКЕН. Если для одного языка установлены несколько вариантов, используется первый вариант, возвращённый Windows.

## Сборка и проверки

Исходный код находится в `src`. Дополнительные NuGet-пакеты и .NET SDK не требуются: используется компилятор .NET Framework из Windows.

```powershell
.\build.ps1 -Test
```

Результат: `dist/TriSwitch/TriSwitch.exe`. Автоматические проверки включают преобразование, словари, сброс буфера, миграцию настроек, новые правила, горячие клавиши, откат регистрации и корректность команды автозапуска. Отчёт — `dist/TriSwitch/self-test-results.txt`. Дополнительный режим `--startup-test` проверяет запуск без появления окна, открытие настроек из трея и возврат в трей при закрытии окна; отчёт — `startup-test-results.txt`. Проверки не включают реальный автозапуск Windows.

Проверка реального ввода запускается отдельно в интерактивном сеансе Windows:

```powershell
Start-Process .\dist\TriSwitch\TriSwitch.exe -ArgumentList '--integration-test' -Wait
```

Она открывает собственное тестовое окно, проверяет фокус перед отправкой клавиш и останавливается, если активно другое окно. Во время этой проверки не переключайте окна и не пользуйтесь клавиатурой. Проверяются автоисправления RU/UK, ручное преобразование, отмена, пароль, исключения, новые сочетания, захват сочетаний в настройках, вставка своих фраз и выбор раскладки. Отчёт — `integration-test-results.txt`. Тест не взаимодействует с пользовательскими документами и использует отдельный `test-preferences.json`, не изменяя ваши настройки.

Словари и условия их использования перечислены в `THIRD-PARTY.md`.
